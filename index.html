To Run Locally:

1. Install Node.js from https://nodejs.org

2. Install PostgreSQL from https://www.postgresql.org

3. Clone the repository:

git clone https://github.com/AHONABASAK2001/college-event-portal.git

4. Setup Backend:

cd backend npm install npm run prisma:migrate npm run seed npm run dev

5. Setup Frontend (new terminal):

cd frontend npm install npm run dev

6. Open in browser: http://localhost:5173
