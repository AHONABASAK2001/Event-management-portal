# College Club & Committee Event Management Portal

A comprehensive web-based platform for managing college events, approvals, registrations, and sponsorships across 12 student clubs and 8 committees.

## Features

✅ **Digital Event Proposals** - Clubs create and track event approvals  
✅ **Calendar Clash Detection** - Real-time venue conflict prevention  
✅ **Multi-Level Approval Workflow** - Faculty Coordinator → Dean approval  
✅ **Student Registration** - Public event listing with QR ticket generation  
✅ **Sponsorship Management** - Sponsor pipeline and deliverable tracking  
✅ **Admin Console** - Institute-wide analytics and reporting  

## Tech Stack

- **Frontend:** React + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** PostgreSQL + Prisma ORM
- **Authentication:** JWT
